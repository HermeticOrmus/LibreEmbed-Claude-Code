# Competitor map: LibreEmbed-Claude-Code

First full-research run, 2026-09-30. Star counts come from the GitHub API on 2026-09-30. Capability claims come from each source's own README, docs or files, read on 2026-09-30. A `?` means we did not find the answer in the source, not that the answer is no.

## Product

- Name: LibreEmbed-Claude-Code, marketplace `libre-embed`, version 1.0.0
- Flagship: `rtos-patterns`, `communication-buses`, `iot-protocols` (the three depth-complete plugins in the 0.2.0 maturity matrix of [CHANGELOG.md](../CHANGELOG.md))
- Our surfaces: 16 plugins in [`.claude-plugin/marketplace.json`](../.claude-plugin/marketplace.json): 15 domain plugins with one agent, one command and one skill each, plus the optional `libre-embed-hooks` plugin (SessionStart, PreToolUse and PostToolUse hooks that ask before flash, erase and secret-file operations). Install paths: `/plugin marketplace add HermeticOrmus/LibreEmbed-Claude-Code`, the `claude plugin` CLI, or `./setup.sh`. Docs: README in English and Simplified Chinese ([README.zh-CN.md](../README.zh-CN.md)); QUICK_START, TROUBLESHOOTING and the three learning paths in English only. No MCP servers, no evals. CI validates the marketplace and every plugin, then installs all of them into a clean config.
