# Kintsugi ledger: LibreEmbed-Claude-Code

Kintsugi mends a broken bowl with gold, so the repair is the part you look at. Here it means every crack we find in this pack is written down with its evidence, sealed with a fix you can check, and kept in this table instead of being patched quietly.

The hallmarked rows shipped in [v1.0.0](https://github.com/HermeticOrmus/LibreEmbed-Claude-Code/releases/tag/v1.0.0) through [#2](https://github.com/HermeticOrmus/LibreEmbed-Claude-Code/pull/2), which was verified by installing every plugin from GitHub into a clean config. For this ledger the released pack was installed from GitHub into a clean Claude Code config again: 16 of 16 plugins enabled. The open rows are cracks the repo already tracks; the Tracker column says where to pick one up.

Grades: **hairline** is copy or cosmetic, **fracture** is wrong behavior with a workaround, **break** means it did not work or broke a safety promise.
